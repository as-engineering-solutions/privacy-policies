# Políticas de privacidad

Páginas públicas de las aplicaciones de AS Engineering Solutions:

- [Network Timer](https://as-engineering-solutions.github.io/privacy-policies/network-timer/)
- [MediaMerge](https://as-engineering-solutions.github.io/privacy-policies/media-merge/)

Los textos editables están en `source/`; los HTML de `docs/` se generan con `scripts/render_policies.py`. El sitio no utiliza analítica, cookies ni recursos de terceros. Los cambios en las prácticas de una aplicación deben reflejarse tanto aquí como en sus declaraciones de Google Play.
