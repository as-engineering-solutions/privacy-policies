# Políticas públicas de AS Engineering Solutions

## Reglas compartidas obligatorias

Antes de modificar, leer completo [RULES.md de engineering-rules](https://github.com/as-engineering-solutions/engineering-rules/blob/main/RULES.md) mediante GitHub autenticado o clon actualizado. Identificar la revisión leída y aplicar las lecciones pertinentes. Si falta acceso, informarlo; no simular la lectura. Las reglas no autorizan compras, publicaciones, instalaciones ni merges.

## Contexto específico

Este repositorio público aloja las políticas de privacidad de las aplicaciones publicadas por AS Engineering Solutions. `source/*.txt` es la fuente editable y `docs/` contiene el sitio estático generado para GitHub Pages. No añadir credenciales, datos de usuarios, tokens, logs, telemetría ni información privada. Antes de cambiar una declaración de datos, contrastarla con el código y con las declaraciones de Play Console de la app correspondiente. Ejecutar `scripts/render_policies.py` y revisar que el texto publicado sea fiel a la fuente. Verificar las tres URL públicas sin iniciar sesión antes de cambiar enlaces de Play Console.
